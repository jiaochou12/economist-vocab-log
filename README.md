> 抓取工具在隔壁仓库 `D:/zcode_date/自动获取文章`（GitHub: xuan250/auto-the-economists），**本仓库只做内容归档与词表沉淀**。

---

## 为什么有这个仓库

- 抓取工具解决"拿得到"的问题，但每期文章和读到的生词散落在桌面，几周后就找不回。
- 生词的沉淀方式沿用最古老也最有效的做法——生词本（单词 | 词性 | 中文意思 | 查询日期），从单词卡、Leitner 卡盒到今天的 Markdown/Docx，形式在变，"例句 + 间隔复习"的核心没变。
- 本仓库把两者放进版本历史：文章按期归档、生词按次追加，每次更新一个 commit，随时可回溯"哪天读了什么、记了什么"。

## 目录结构

```
经济学人与生词表更新/
├── README.md          本说明 + 更新记录

└── 工具/
    └── 记单词.py      追加生词，自动去重，双写仓库 + 桌面单词本
```

## 更新流程

1. **文章更新**：运行隔壁下载器（`economist_app.py`）勾选当期文章，把生成的文章文件移入 `文章/年/月/`，命名 `YYYY-MM-DD_标题.docx`。
2. **生词更新**：阅读时查到的词随手记录——

   ```bash
   python 工具/记单词.py lucrative adj. "获利丰厚的；赚大钱的（a lucrative business）"
   ```

   - 同一单词重复查询**不重复记录**（按单词小写去重）
   - 同时写入仓库 `生词表/单词本.docx` 和桌面 `作业文件\单词本.docx`（后者是全局约定的固定位置）
   - 单词本不存在时自动按四列表格创建
3. **提交**：`git add -A && git commit -m "update: 2026-09-29 期 + 5 个生词"`。

## 约定

- 生成的文档一律 `.docx`，不产出 `.doc` / `.pdf` 等其他格式。
- 生词表表格固定四列：**单词 | 词性 | 中文意思 | 查询日期**。
- 不提交个人账号、密码等敏感信息。
